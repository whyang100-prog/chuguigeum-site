# 축의금 얼마하지?

Turso(libSQL) + Node.js + Render 기반 경조사 서비스.

## 기능

- 예식장 검색, 식대·친밀도·참석 인원 기반 축의금 참고 계산
- 로그인/회원가입/로그아웃, 비밀번호 변경, 회원 탈퇴
- 본인 전용 축의금·조의금 기록 (낸 돈/받은 돈, 수정/삭제/검색/합계)
- 명시적으로 동의한 익명 사용자 사례, 관리자 승인, 조건별 참여자 수와 중앙값
- 결혼식 복장/주의 사항, 종교별 장례식 예절 안내
- 관리자 회원 정지/해제 및 사례 승인/반려

초기 예식장 데이터는 60곳이며 가격 참고가 44곳, 미공개 16곳입니다. 전국 전체 목록이나 최신 확정 계약가가 아닙니다. 실제 사용자 사례는 초기값 없이 시작합니다.

## 실행

Node.js 22 이상. .env.example을 .env로 복사해 Turso libSQL URL과 토큰을 입력하세요.

```sh
npm ci
npm run db:seed
npm start
```

http://localhost:3000 에서 열 수 있습니다. 환경변수 없이 실행하면 기존 계산기만 개발용 데이터로 동작하고 계정·기록 기능은 사용할 수 없습니다. 운영에서는 원격 Turso 연결이 필수입니다.

## 배포와 관리자 생성

**UPDATE-V2.md**에 기존 Windows 프로젝트 덮어쓰기, 관리자 생성, GitHub push 및 Render 재배포 방법이 있습니다.

```sh
npm run admin:create
```

이 명령은 별도로 설정한 ADMIN_USERNAME과 ADMIN_PASSWORD를 사용합니다. 관리자 비밀번호를 저장소나 public 폴더에 넣지 마세요. 기존 일반 회원을 자동으로 관리자로 승격하지 않습니다.

Render의 buildCommand는 npm ci && npm run db:seed, startCommand는 npm start입니다. 기존 예식장 데이터를 유지하고 새 테이블만 추가합니다.

## 검증

npm test: 계산, 데이터 무결성, HTTP 응답, 계정과 권한, 기록 소유권, CSRF 출처 확인, 사례 검토와 집계, 세션 폐기를 임시 로컬 libSQL DB로 검사합니다. 브라우저 시각 검사와 운영 Turso/Render 배포 검증은 별도입니다.

## 자료

종교·가정에 따라 예절이 다를 수 있으며 현장 안내를 우선합니다. 예절 가이드에 출처를 표시합니다. 공개 사례는 회원 자기보고이며 지급 사실 인증이 아니고 자발적 표본이므로 전체 하객을 대표하지 않습니다.
